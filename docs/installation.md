# Installation

## Requirements

- Node.js 16+
- npm

## Install Nodelly

```bash
npm install nodelly
```

## Importing

```js
const nodelly = require("nodelly");
```

## Individual Modules

```js
const regexes = nodelly.Regexes;
const sort = nodelly.Sort;
const checker = nodelly.Checker;
const validator = nodelly.Validator;
const manager = nodelly.Manager;
```

## Verify Installation

```js
console.log(nodelly);
```

If no errors appear, Nodelly has been installed successfully.

# Validator

The Validator module provides easy validation for common user input.

## Examples

### Email

```js
Validator.isValidEmail(
    "test@example.com"
);
```

### Username

```js
Validator.isValidUsername(
    "AlkoRichy"
);
```

### Password

```js
Validator.isValidPassword(
    "StrongP@ss123"
);
```

## Supported Validators

- Email
- Username
- Password
- IP Address
- Phone Number
- Date
- Time
